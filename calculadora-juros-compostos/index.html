How to use this tool

  1. Informe o salário e os dados do contrato: Use valores brutos e selecione as opções aplicáveis ao cálculo trabalhista.
  2. Revise o resultado: Confira os componentes, impostos, descontos e memória de cálculo exibidos na página.
  3. Valide casos formais: Use o resultado como estimativa e confirme a folha oficial com RH, contador, sindicato ou profissional habilitado.

About this tool

Esta calculadora mostra a evolução de um investimento com juros compostos, separando valor investido, juros acumulados e saldo final. Use como simulação matemática, não como recomendação financeira.

FAQ

Como calcular juros compostos?

Use a fórmula montante = capital × (1 + taxa)^tempo, somando aportes quando existirem.

A calculadora aceita aportes mensais?

Sim, ela considera aporte inicial, aportes recorrentes, taxa e prazo.

O resultado é recomendação de investimento?

Não. É uma simulação matemática para planejamento.
