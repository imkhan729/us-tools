# USOnlineTools.com — 400-Tool On-Page SEO, Keyword & SERP Research Master Plan

> **Website:** https://usonlinetools.com/  
> **Scope:** On-page SEO only: keyword research, SERP competitors, semantic SEO, content quality, title/meta/H1, internal linking, cannibalization, thin-content cleanup, and carefully gated programmatic SEO.  
> **Inventory:** 400 core tools across 16 category sitemaps.  
> **Primary market:** United States first; then UK, Canada, Australia and selected high-value European markets.  
> **Execution engine:** Antigravity.  
> **Goal:** Give every existing tool the best realistic keyword cluster, analyze 3 live competitors per tool, strengthen page usefulness and semantic coverage, and prioritize pages capable of reaching Google's top 10.

---

# 1. Non-Negotiable Rules

Antigravity must:
1. Research every existing canonical tool URL before changing it.
2. Analyze the live Google SERP for every tool.
3. Record **3 real competitor pages from 3 different domains** for every tool.
4. Use quantitative keyword data when available.
5. Never invent search volume, KD, CPC, traffic potential, DR/AS, or rankings.
6. If Semrush/Ahrefs/Ubersuggest/Keyword Planner data is unavailable, write `DATA NOT AVAILABLE`.
7. Use GSC historical data as evidence, but never call GSC impressions "search volume."
8. Give each canonical URL **one primary search-intent cluster**.
9. Prefer improving an existing page over creating another overlapping URL.
10. Do not create pages for every number, salary, date, city, unit value, or keyword permutation.
11. Never copy or closely paraphrase competitor text.
12. Preserve correct calculator/tool functionality.
13. Keep the actual tool near the top of the page.
14. Do not optimize to arbitrary word counts.
15. Use official/primary sources when facts can change.
16. Avoid unsupported medical, tax, financial, or regulatory claims.
17. Log every on-page change for later GSC comparison.


Priority Bands:
- **P0 (85–100)**: Immediate high-priority focus
- **P1 (70–84)**: Strong growth opportunities
- **P2 (55–69)**: Solid secondary utilities
- **P3 (40–54)**: Standard utility maintenance
- **P4 (0–39)**: Low search demand / niche maintenance
