## 2. Opportunity Scoring Formula & Priority Tiers

The opportunity score is calculated using the weighted formula:
```text
Opportunity Score (0-100) = Demand Score (0-25) + SERP Weakness (0-25) + Intent Fit (0-20) + Feature Gap (0-15) + Tier-1 Country Value (0-10) + GSC Evidence (0-5)
```

### Priority Tier Distribution:
- **P0 Tier (Score 85–100) — 0 Tools**: Immediate strategic focus. High-demand developer tools, construction estimators, CSS generators, and time calculators where competitor SERPs suffer from high ad clutter, slow execution, or lack of step-by-step guidance.
- **P1 Tier (Score 70–84) — 373 Tools**: Core mathematical, unit conversion, financial, and fitness calculators with steady long-term traffic potential.
- **P2 Tier (Score 55–69) — 27 Tools**: Niche gaming calculators and specialized social media utilities.
- **P3 / P4 Tier (<55) — 0 Tools**: Zero tools fall into low-value tiers.
