## 3. Blueprint Quality Standards

Every brief enforces:
1. **Frontloaded Exact-Match Keyword**: Keyword positioned in the first 35 characters of the title tag.
2. **Click-Worthy Value Proposition**: Meta description emphasizes free usage, client-side privacy, and specific differentiator.
3. **Structured Entity Support**: Formulas rendered in standard notation and accompanied by tabular examples.
4. **FAQ Schema Inclusion**: Valid FAQPage JSON-LD schema matching visible text 100%.
