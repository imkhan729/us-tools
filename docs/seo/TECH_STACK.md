# Technical Stack Baseline — USOnlineTools.com

- **Framework**: React 19 (via `@vitejs/plugin-react`)
- **Language**: TypeScript 5.9 / TSX with Node.js CommonJS build and audit scripts
- **Frontend Library & UI**: Tailwind CSS v4, Radix UI primitives, Lucide React icons, Framer Motion, Recharts
- **Router**: Wouter v3 (`wouter` Switch, Route, Router)
- **Package Manager**: pnpm v10.32.1 (configured via pnpm workspace)
- **Build System**: Vite 6+ with automated pre/post build pipeline (`generate:seo` -> `vite build` -> `build:static-seo-pages` -> `export-static-for-hostinger`)
- **Rendering Method**: Client-Side Hydration on top of Prerendered Static HTML
- **Static Generation**: Custom Node.js static generator (`scripts/build-static-seo-pages.cjs`) producing static `index.html` pages for all tools and categories in `dist/public`
- **Server-Side Rendering**: None (pure static hosting with client-side SPA routing fallback)
- **Hostinger Deployment Model**: Static export to Hostinger `public_html` / Git deployment with Apache `.htaccess` rewrite rules
- **Environment Variables**: `PORT`, `BASE_PATH` (Vite dev/build)
- **SEO Library**: `react-helmet-async` for client-side head management + static HTML injection in build pipeline
- **Metadata Implementation**: `<SEO />` component (`src/components/SEO.tsx`) and `TOOL_STATIC_OVERRIDES` in static builder
- **Schema Implementation**: JSON-LD structured data (WebSite, WebPage, SoftwareApplication)
- **Sitemap Implementation**: Modular XML sitemap index (`sitemap.xml`) with category sub-sitemaps generated by `scripts/generate-seo-assets.cjs`
- **Robots Implementation**: `robots.txt` generated into `public/robots.txt`
- **Redirect Implementation**: Apache `.htaccess` 301 redirects mapping legacy paths (`/tools/:slug`) to canonical `/:category/:slug` plus SPA fallback `RewriteRule ^ index.html [L]`
- **Analytics Implementation**: Missing in repository baseline (marked for Phase 15 implementation)
